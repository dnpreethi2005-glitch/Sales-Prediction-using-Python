# Sales Prediction using Python

## Overview
This project predicts sales based on TV, Radio, and Newspaper advertising budgets using Machine Learning.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

## Algorithm
Linear Regression

## Features
- Data preprocessing
- Train-test split
- Linear Regression model
- Sales prediction
- R² score evaluation
- Data visualization

## Accuracy
89.94%

## Dataset
Advertising.csv
